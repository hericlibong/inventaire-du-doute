# Images de couverture — accueil

Illustrations **générées pour le projet** (composition abstraite d'archive / d'index
de données). Elles évoquent la **base de données Joconde** du ministère de la Culture
— son imaginaire de notices, de fiches, d'open data — et **non** Léonard de Vinci ni
le tableau *La Joconde* comme œuvre (le visage n'est qu'un motif de données parmi les
blocs, cadres et fiches).

- `accueil-desktop.png` — asset horizontal (1672 × 941), écrans larges.
- `accueil-mobile.png` — composition verticale autonome (941 × 1672), téléphones.

Statut droits : illustrations produites pour ce projet (génération par IA). Outil de
génération : fourni par l'auteur du projet — à préciser. Les textes et la navigation
sont des éléments HTML superposés, jamais intégrés au bitmap.
